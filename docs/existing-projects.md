# 기존 프로젝트를 대시보드에 올리기

이미 진행 중이거나 홀드해 둔 프로젝트를 대시보드에 올리는 방법입니다. ([PC 설정](pc-setup.md)을 먼저 마쳐야 해요.)

## 방법 1: 자동 (아무것도 안 해도 됨)

그 프로젝트를 다음에 Claude Code나 Codex로 작업하면, 작업이 끝날 때 저절로 등록됩니다.

## 방법 2: 지금 바로 (AI에게 부탁)

프로젝트 폴더에서 Claude Code나 Codex를 열고 이렇게 말합니다.

- "대시보드에 이 프로젝트 등록해줘"
- 홀드 중인 프로젝트라면: "대시보드에 홀드로 등록해줘"

AI가 계획 문서, README, 커밋 기록을 살펴 진행률, 지금 단계, 다음 과제를 추정해서 올립니다.

## 방법 3: 직접 입력

```
py "$HOME/.dashboard/dash_update.py" set --id my-project --name "내 프로젝트" --progress 40 --status paused --next "다시 시작할 때 할 일"
```

(macOS/Linux는 `py` 대신 `python3`)

## 상태 바꾸기

- 폰 웹앱: 프로젝트 카드의 `⋯` 버튼 → **진행 중 / 홀드 / 완료 / 대시보드에서 빼기**
- PC에서 AI에게: "이 프로젝트 홀드해줘", "완료 처리해줘", "대시보드에서 빼줘"

홀드나 완료였던 프로젝트도 PC에서 다시 작업하면 자동으로 **진행 중**으로 돌아옵니다.
