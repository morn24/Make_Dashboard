# 업무계획서: 개인 대시보드 (할 일 + 프로젝트 진행률)

작성일: 2026-10-29

## 1. 목표

갤럭시 S25 **배경화면 위젯**에서 다음 두 가지를 한눈에 본다.

1. **오늘 할 일**: 매일 반복하는 일과 한 번만 하는 일. 폰에서 체크하고 추가할 수 있다.
2. **프로젝트 진행 상황**: PC에서 Codex나 Claude Code로 진행하는 프로젝트의 진행률(%), 지금 하는 일, 다음 과제.

## 2. 핵심 설계 원칙 (제1원칙으로 정리)

| 질문 | 결론 |
|---|---|
| 데이터는 어디에 둬야 PC와 폰 모두 쓸 수 있나? | 무료이고 이미 쓰고 있는 **GitHub 비공개 저장소** (`morn24/dashboard-data`) |
| 폰과 PC가 동시에 고치면 어떻게 되나? | 파일을 **둘로 나눈다** (폰 → `todos.json`, PC → `projects.json`). 겹쳐도 `sha` 확인 후 재시도한다 |
| 웹앱만으로 위젯이 되나? | **안 된다.** 안드로이드는 웹앱 위젯을 지원하지 않는다 → 위젯은 **네이티브 앱**으로 만든다 |
| 서버가 필요한가? | **필요 없다.** 웹앱, 위젯, PC 모두 GitHub API를 직접 호출한다 |
| 진행률은 누가 적나? | 작업을 실제로 한 **AI 에이전트**가 작업이 끝날 때 스크립트로 적는다 |

## 3. 전체 구조

```
 [PC] Codex / Claude Code
   │  작업 단위가 끝나면 dash_update.py 실행
   ▼
 GitHub 비공개 저장소  morn24/dashboard-data
   ├─ data/todos.json      (할 일)
   └─ data/projects.json   (프로젝트 진행)
   ▲                ▲
   │ 읽기/쓰기       │ 읽기 (+ 할 일 체크)
 [웹앱]            [안드로이드 위젯]
 GitHub Pages      갤럭시 S25 홈 화면
```

데이터 형식은 [`docs/data-format.md`](data-format.md)에 정리했다. **세 프로그램이 모두 이 문서를 따른다.**

## 4. 단계별 계획

| 단계 | 내용 | 작업 장소 | 상태 |
|---|---|---|---|
| 1 | 데이터 구조 설계 + 데이터 저장소 생성 | 클라우드 | ✅ 완료 |
| 2 | 웹앱 대시보드 (PWA) + GitHub Pages 배포 설정 | 클라우드 | ✅ 완료 (https://morn24.github.io/Make_Dashboard/ 배포, 폰 설치) |
| 3 | PC 자동 업데이트: `dash_update.py` + Codex/Claude Code 규칙 | **로컬 PC** | ✅ 완료 ([설치 안내](pc-setup.md), [전역 규칙](agent-rule.md)). 실제 토큰 연결과 자동 갱신은 사용자 확인 필요 |
| 4 | 안드로이드 위젯 앱 | **로컬 PC** (Android Studio) | ⬜ [수행지시문 02](instructions/02-android-widget.md) |
| 5 | Google 캘린더 오늘 일정 연동 (Apps Script → `calendar.json`) | 브라우저 (script.google.com) | 🟡 코드와 웹앱 완료, 사용자 설치 필요: [설정 안내](google-calendar-setup.md) |

### 단계 3: PC 자동 업데이트 (예상 1~2시간)

- 산출물: `scripts/dash_update.py`, 전역 규칙 파일(`~/.claude/CLAUDE.md`, `~/.codex/AGENTS.md`)에 추가할 문구
- 완료 기준: 아무 프로젝트에서 AI에게 작업을 시키면, 작업 후 웹앱에 진행률과 다음 과제가 자동으로 바뀐다.

### 단계 4: 안드로이드 위젯 (예상 반나절~하루)

- 산출물: `android/` 폴더의 Kotlin 프로젝트, 폰에 설치된 앱과 위젯
- 완료 기준
  - 홈 화면에 위젯을 추가하면 오늘 할 일 진행률, 미완료 할 일, 프로젝트별 진행률과 다음 과제가 보인다.
  - 위젯에서 할 일을 탭하면 완료로 바뀌고, 웹앱에도 반영된다.
  - 30분 이내 주기와 새로고침 버튼으로 갱신된다.

## 5. 위험 요소와 대응

| 위험 | 대응 |
|---|---|
| 토큰 유출 | 토큰 권한을 **`dashboard-data` 저장소 하나, Contents 읽기/쓰기만** 주고 만료일을 설정한다. 코드나 저장소에는 절대 넣지 않는다 |
| 폰과 PC 동시 수정 충돌 | 파일을 분리하고, `sha` 충돌이 나면 다시 읽고 다시 적용한다 (덮어쓰기 금지) |
| GitHub Pages는 무료 계정에서 **공개 저장소만** 가능 | 코드 저장소(`Make_Dashboard`)만 공개로 바꾼다. 개인 데이터는 **비공개 `dashboard-data`** 에 있으므로 노출되지 않는다 |
| 삼성 배터리 최적화로 위젯 갱신이 늦어짐 | 앱을 "절전 예외"에 등록하고, 위젯에 수동 새로고침 버튼을 둔다 |
| GitHub API 요청 한도 | 인증 요청은 시간당 5,000회라서 1분 주기 웹앱과 15~30분 주기 위젯으로는 충분하다 |
